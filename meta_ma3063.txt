## Enable SSH via web (cara 1 - semua versi)
Buka http://192.168.10.1/__factory_verify_mode__ -> otomatis buka port SSH
Lalu login SSH: admin / wifi@cmcc
Catatan: setelah terkoneksi internet, login SSH bisa diblokir (faktor cloud CMCC).
Cara 2 (versi < Juni 2023): System > System Upgrade > ketuk Device Model 5x lalu
Current Version 5x untuk buka mode developer (SSH + port 8088).
